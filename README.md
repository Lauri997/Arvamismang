Arvamismäng – Number Guessing Game
1. Projekti nimi

Arvamismäng (Number Guessing Game)

2. Projekti eesmärk

Projekti eesmärk on luua lihtne ja lõbus arvamismäng, kus arvuti valib juhusliku arvu ning mängija ülesanne on see võimalikult väheste katsetega ära arvata.

Projekti käigus soovin õppida JavaScripti kasutamist, tingimuslauseid, tsükleid, muutujaid ja kasutaja sisendi töötlemist.

3. Sihtgrupp

Mäng on mõeldud lastele, noortele ja kõigile inimestele, kellele meeldivad lihtsad nuputamis- ja arvamismängud.

4. Projekti funktsioonid
Juhusliku arvu genereerimine – arvuti valib juhusliku arvu vahemikus 1–100.
Mängija pakkumine – mängija saab sisestada oma arvatud numbri.
Vihjete andmine – mäng annab teada, kas õige arv on suurem või väiksem.
Katsete lugemine – mäng loendab, mitu korda mängija on arvanud.
Punktide arvestamine – mängija saab rohkem punkte, kui arvab õige numbri väheste katsetega.
Mängu uuesti alustamine – mängija saab alustada uut mänguringi.
Tulemuste salvestamine – mäng salvestab mängija parimad tulemused.
Tulemuste võrdlemine – mängija saab vaadata oma varasemaid tulemusi.
5. Kavandatud tehnoloogiad
HTML – mängu veebilehe struktuur.
CSS – mängu kujundus ja välimus.
JavaScript – mängu loogika ja funktsioonid.
Visual Studio Code – koodi kirjutamiseks.
GitHub – projekti failide säilitamiseks ja haldamiseks.
JSON – mängutulemuste salvestamiseks.
6. Projekti teostamise etapid
Loon GitHubis projekti koodihoidla.
Koostan HTML-faili mängu põhistruktuuriga.
Kujundan mängu CSS-i abil.
Programmeerin JavaScriptiga juhusliku arvu genereerimise.
Lisan mängija sisendi kontrollimise ja vihjete süsteemi.
Lisan katsete ja punktide arvestamise.
Lisan tulemuste salvestamise ja uue mängu alustamise võimaluse.
Testin mängu ning parandan leitud vead.
7. Valmisoleku kriteeriumid

Projekt on valmis, kui:

Mäng genereerib iga mänguringi alguses juhusliku arvu vahemikus 1–100.
Mängija saab sisestada oma pakkumise.
Mäng annab vale pakkumise korral õige vihje.
Mäng tuvastab õige vastuse.
Mäng loendab katseid ja arvutab punktid.
Mängija saab alustada uut mänguringi.
Tulemused salvestatakse ja neid saab hiljem vaadata.
Mäng töötab vigadeta ning seda saab kasutada veebibrauseris.
8. Projekti hetkeseis

Projekt on planeerimise etapis. Järgmisena alustan mängu programmeerimisega.
